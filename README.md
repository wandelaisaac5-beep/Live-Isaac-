# Live-Isaac-

Live-Isaac- is a lightweight live chat project focused on creating a quick and engaging conversation experience. The goal is to give a user their first chance to enter the chat and continue interacting for up to 3 minutes after the session closes.

## Overview

- Quick entry into a live conversation
- Short, focused chat sessions
- Opportunity to reconnect or continue engagement shortly after a session ends

## Purpose

This repository is intended to serve as the foundation for a simple chat experience where user interaction is brief, conversational, and designed to encourage return engagement.

## Getting Started

1. Clone the repository.
2. Install the required dependencies.
3. Run the application locally.

## Notes

The project is currently in its early stage and may evolve as the chat experience and product requirements are defined.
